# Aman's Travels

This repository hosts a small mock site for Aman's Travels. The site is a static HTML site and can be published via GitHub Pages.

To publish the site manually:
1. In the repository, go to Settings → Pages.
2. Under "Build and deployment", select the branch `main` and folder `/` (root).
3. Save — the site should publish at: `https://TeredaTrades.github.io/Amanstravels/`.

I can also add a GitHub Action to publish to `gh-pages` branch automatically if you prefer that workflow.
