# Aman's Travels

This repository hosts a small mock site for Aman's Travels. The site is a static HTML site, deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.

Live at: `https://TeredaTrades.github.io/Amanstravels/`

Deployment is handled by `.github/workflows/pages.yml` — no manual steps required. Pushing to `main` triggers a build and deploy automatically.
